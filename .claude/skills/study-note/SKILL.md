# 학습 노트 작성

사용자는 이 프로젝트로 BE 개발을 학습한다. 노트는 **양보다 읽기 쉬움**이 우선이다.

## 절차

1. `docs/study/README.md` 목차를 읽고 같은 개념의 노트가 있는지 확인한다. 있으면 새로 만들지 않고 그 노트를 보강한다.
2. 위치: `docs/study/<주제>/<개념>.md` (주제 예: `spring`, `jpa`, `testing`, `ai`). 파일 이름은 영어 소문자-하이픈.
3. 아래 형식으로 쓴다 (60~90줄 목표).
4. `docs/study/README.md` 목차 표에 한 줄을 추가한다 (순서 · 노트 링크 · 한 줄 요약 · 관련 작업 ID).
5. `python3 scripts/check-doc-links.py` 로 링크를 확인한다.
6. 노트는 해당 작업 PR 에 함께 커밋한다. `docs/public`(팀 문서)에는 쓰지 않는다.

## 형식 (이 순서)

```markdown
# <개념 이름>

## 한 줄 요약
## 이 프로젝트에서 일어난 일      ← 실제 파일·클래스·결함 ID 로. 왜 알아야 하는지
## 동작 원리                      ← 그림이나 흐름 하나 (코드 블록 ASCII)
## 코드로 보기                    ← ✗ 잘못된 예 / ✓ 맞는 예, 각 10줄 이내
## 기억할 것                      ← 3개 이내
## 더 읽을거리                    ← 공식 문서 링크 1~3개
```

## 지킬 것

- 이모지 금지. 확인 안 된 주장은 "(estimated)" 로 표시한다.
- 공식 문서 링크는 실제로 열어 확인한 것만 넣는다.
- 이 저장소에서 실행으로 확인한 사실이면 근거 문서(`docs/ai/context/current-state.md` §…)를 적는다.
