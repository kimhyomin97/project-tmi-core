# v0.2.0 — 2026-11-09

Toss 보유자산 스냅샷 MVP (preview, 진행 중).

## Added

- Toss 보유자산 스냅샷 도메인 (`toss_holdings_snapshot` 테이블, 엔티티, 리포지토리)
- Toss OAuth 2.0 Client Credentials 인증 (`TossAuthClient`, `TossTokenProvider`)
- Toss `/holdings` HTTP Interface 클라이언트 (`TossHoldingsClient`)
- 스케줄러 활성화 (`@EnableScheduling`) 및 `TossProperties` 설정 바인딩
- 설계 문서 2 종 (`docs/public/toss/00_인증.md`, `01_보유자산스냅샷.md`)

## Known limitations

- 수집 서비스·스케줄러 미완 (Step 9-10 예정)
- 다중 계좌 미지원 (단일 계좌 프로퍼티 고정)
- 종목별 시계열 미저장 (원본 응답 JSONB 백업만)
